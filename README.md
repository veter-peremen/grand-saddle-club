# Grand Island Saddle Club — desktop HTML

Десктопная HTML/CSS/JS-верстка по фрейму Home · Desktop · 1440.

## Открыть
Откройте index.html в браузере. Установка зависимостей и сборка не нужны.
Все изображения и шрифты хранятся в assets; подключение к интернету для страницы не требуется.

## Файлы
- index.html — семантическая разметка.
- styles.css — оформление, сетка и адаптивные стили.
- script.js — диалоговые окна.
- source-sans-3.css, roboto-slab.css — локальные шрифты.
- assets/ — исходная графика из Figma и шрифты.

## Поведение
Навигация прокручивает к секциям. Кнопки открывают информационные окна.
Бронирование и личный кабинет не подключены к серверу; предусмотрена ссылка для звонка в клуб.
Точное меню, авторизация и онлайн-бронирование требуют подключения соответствующих сервисов.
